## Slide 2: The Problem

### Current Learning Challenges
- **Information Overload**: Too many courses, not enough guidance
- **One-Size-Fits-All**: Static content doesn't adapt to individual needs
- **Isolation**: Learning alone without peer support or motivation
- **Goal Uncertainty**: Learners struggle to define and track learning paths
- **Fragmented Resources**: Courses, research, and recommendations are scattered

### The Gap
Existing platforms focus on content delivery, not personalized learning journeys.

---

## Slide 3: Our Solution

### IFA — Your Intelligent Learning Companion

IFA uses AI to create a personalized, adaptive, and social learning experience:

1. **AI-Powered Recommendations**: Three-model pipeline for intelligent course suggestions
2. **Adaptive Learning Paths**: Content adjusts based on assessment performance
3. **Social Learning**: Connect with peers, compare progress, and share courses
4. **Research Integration**: Scholarxiv and YouTube resources integrated into learning
5. **Goal-Oriented**: Clear milestones and progress tracking

---

## Slide 4: How It Works

### The Three-Model Pipeline

**Model 1: Conversational Learning Advisor**
- Natural language interface for learning queries
- Understands goals and preferences
- Orchestrates research and course generation

**Model 2: Course Architect**
- Generates course structure and modules
- Leverages Scholarxiv and YouTube for content
- Creates just-in-time, JIT materialization

**Model 3: Fine-Tuned Course Builder**
- Builds detailed lesson content
- Adapts based on assessment results
- Refines content for optimal learning

## Slide 6: Technology Stack

### Frontend
- **SvelteKit 2 + Svelte 5**: Modern, performant reactive framework
- **TypeScript**: Type-safe development
- **Tailwind CSS**: Utility-first styling with IFA design system

### Backend
- **ASP.NET Core (.NET 10)**: High-performance, scalable API
- **Clean Architecture**: Separation of concerns for maintainability
- **Entity Framework Core**: ORM for PostgreSQL database
- **PostgreSQL**: Reliable, open-source database

### AI & Integrations
- **Gemini AI**: Conversational AI model
- **Groq AI**: Fast inference for course generation
- **Scholarxiv**: Academic research integration
- **YouTube**: Video resource integration

### DevOps
- **Docker**: Containerization for easy deployment
- **EthioDeploy**: Deployment automation
- **STARK Changelog**: Milestone tracking

## Slide 7: Architecture

### Clean Architecture Layers

```
┌─────────────────────────────────────┐
│       Presentation Layer            │
│   (SvelteKit Frontend + API)       │
├─────────────────────────────────────┤
│       Application Layer             │
│   (Business Logic & Services)      │
├─────────────────────────────────────┤
│         Domain Layer               │
│   (Entities & Value Objects)        │
├─────────────────────────────────────┤
│     Infrastructure Layer           │
│   (Data Access & External APIs)    │
└─────────────────────────────────────┘
```

### Key Benefits
- Testability: Each layer can be tested independently
- Maintainability: Clear separation of concerns
- Scalability: Easy to add new features or modify existing ones
