# Functional Requirements

## FR-01 Authentication
Users can register, authenticate, logout and access protected resources.

## FR-02 Learner profile
The system stores learner goals, level, language, preferences, skills and constraints.

## FR-03 AI onboarding
The AI can ask relevant onboarding questions and produce a structured learner profile.

## FR-04 Research
The system can create research requests and normalize ScholarXiv and practical resources into a research package.

## FR-05 Course planning
The AI can create a course blueprint from learner context and research.

## FR-06 On-demand module generation
The system generates the current module when needed instead of generating every lesson upfront.

## FR-07 Learning
Learners can open modules, lessons and resources and record completion.

## FR-08 Assessment
The system can generate and serve quizzes and assessments and store attempts/results.

## FR-09 AI tutor
Learners can ask questions about the current course and receive contextual explanations.

## FR-10 Progress and skills
The backend stores progress, assessment results and skill state.

## FR-11 Adaptation
The application can use learning state to influence subsequent learning/module generation.

## FR-12 Public learning
Users can discover, publish and share permitted courses.

## FR-13 Voice
Voxide can be used to start or continue supported application interactions through voice.
