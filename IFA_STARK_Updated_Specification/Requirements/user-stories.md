# User Stories

- As a learner, I want to describe what I want to learn so the system can create a suitable learning path.
- As a learner, I want my goals and skills saved so I do not repeat onboarding unnecessarily.
- As a learner, I want research-backed resources before my course is generated.
- As a learner, I want only the module I need to be generated when I reach it.
- As a learner, I want to ask an AI tutor questions about what I am studying.
- As a learner, I want quizzes and assessments to measure my understanding.
- As a learner, I want my scores and progress saved.
- As a learner, I want weak areas to influence what I study next.
- As a learner, I want to discover public courses.
- As a creator, I want to publish a course.
