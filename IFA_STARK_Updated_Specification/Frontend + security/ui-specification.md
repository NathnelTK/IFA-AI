# UI Specification

## Status

The planned frontend UI has already been implemented.

The backend team should not rebuild the UI. Work should focus on supplying real data and behavior through the API.

Implemented product areas include:

- dashboard
- continue learning
- public courses
- learner skills/progress
- recommendations/activity areas
- AI tutor entry
- course learning screens
- research areas
- profile/settings/navigation

Backend integration should replace mock data with real API data progressively.
