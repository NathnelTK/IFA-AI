# Voice Workflow

Voxide is used for voice interaction with the application.

```text
Voice input
 ↓
Voxide
 ↓
Text / intent
 ↓
.NET API
 ↓
Supported application action or AI workflow
 ↓
Response
```

Voice should not be treated only as a voice-message feature. It should be able to initiate or continue supported learning interactions.
