# Course Generation Workflow

```text
LearnerProfile
+
ResearchPackage
        ↓
Ollama course-planning workflow
        ↓
CourseBlueprint
        ↓
Current Module
        ↓
Ollama content-generation workflow
        ↓
Lesson + exercises + resources + assessment
```

The system does not need to generate every future lesson immediately. Generate the current module when needed and keep future modules as specifications where practical.
