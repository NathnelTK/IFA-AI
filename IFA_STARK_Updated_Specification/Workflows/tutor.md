# AI Tutor Workflow

The tutor uses the same Ollama model with a tutor-specific prompt and context.

Context can include:

- current course
- current module
- current lesson
- relevant course resources
- learner level
- learner progress
- recent assessment results
- relevant skills/weaknesses

Example requests:

- Explain this differently
- Give me another example
- Why is my answer wrong?
- Help me understand this topic
- Give me a practice question
- What should I review next?

The tutor should not invent course facts when the required course context is unavailable.
