# Assessment Workflow

```text
Learner
 ↓
Quiz/Assessment
 ↓
Answers
 ↓
Submission
 ↓
Backend evaluation
 ↓
Attempt result
 ↓
Skill signals
 ↓
Learning state
```

Where deterministic answer evaluation is possible, it should happen in application code rather than relying on an LLM to decide objective correctness.
