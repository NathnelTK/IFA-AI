# Onboarding Workflow

```text
Learner
 ↓
AI onboarding conversation
 ↓
Learner goal + level + constraints + preferences
 ↓
Structured LearnerProfile
 ↓
Backend validation
 ↓
Database
 ↓
Research request
```

The learner can later edit the profile directly through the UI or describe a change to the AI. Both routes update the same backend profile.
