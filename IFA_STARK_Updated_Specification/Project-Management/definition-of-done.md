# Definition of Done

A backend PR is complete when:

- implementation is in the correct Onion Architecture layer
- request/response contracts are defined
- validation is present
- database migration is included when required
- errors are handled
- tests are added where appropriate
- API is tested locally
- no secrets are committed
- documentation is updated when a contract changes
- STARK changelog is updated for meaningful changes
- PR has been reviewed
- review comments are resolved
- PR is merged
