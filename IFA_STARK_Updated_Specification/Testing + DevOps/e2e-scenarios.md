# E2E Scenarios

## Scenario 1
Register → onboard → profile saved → research created.

## Scenario 2
Research completed → course blueprint generated → current module generated.

## Scenario 3
Learner studies → takes quiz → score saved → progress updated.

## Scenario 4
Learner asks tutor a question → tutor receives course context → response returned.

## Scenario 5
Assessment identifies weak area → learning state changes → next learning step uses the updated state.

## Scenario 6
Course published → appears in public courses → another learner can enroll.
