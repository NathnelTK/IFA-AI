# Product Scope

## In scope

- Learner onboarding and profile creation
- Personalized learning goals
- Research through ScholarXiv MCP and practical web/video resources
- AI-generated course blueprints
- On-demand module generation
- Learning content and resources
- Quiz and assessment generation
- AI tutor/course guide
- Learner progress and skill state
- Adaptive next-step decisions
- Public courses
- Course sharing and permitted progress comparison
- Authentication, profile, settings, notifications and search
- Voice interaction through Voxide
- Docker, deployment and hackathon demo support

## Current implementation boundary

The frontend UI for the planned product areas has already been implemented. Backend work should connect the existing UI to real APIs and data rather than rebuilding the UI.

## Out of scope for the hackathon

- Training a new foundation model
- Fine-tuning a model
- Maintaining separate trained models for every AI feature
- Building a completely independent AI system for every workflow
